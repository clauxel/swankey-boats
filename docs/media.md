# Media

- `swankey-water-film.mp4`: 12-second lake and aerial edit from the 35.864-second boating film used by the reference at http://www.kimpleboats.com.cn/; source path `/qfy-content/uploads/2024/06/733dd2a7b9140d67a54fa04c8b595659.mp4`. Four actual camera shots each last 3 seconds with retimed playback: open-lake aerial, waterline wake, distant boat and wake, then overhead circular wake. The opening green-boat close-up at source 6.0–6.8 seconds and former final close-up at source 16.2–18.5 seconds are omitted. Source ranges are bounded inside scene cuts to avoid short flashes within a nominal edit segment.
- `film-poster.jpg`, `lake-run.jpg`, `fishing.jpg`, `waterline.jpg`, `deck.jpg`, `horizon.jpg`: still frames from that film, used for boating ambience. Frames with visible reference-brand marks are excluded. They are not E498 product-performance evidence.
- `swankey-e498-film.mp4` and `e498-film-poster.jpg`: compatibility aliases for the current lake film and poster, so previously opened players receive the same current media.
- `e498-design.png`: generated Swankey electric bass-boat design illustration, with graphite hull and blue details. Final configuration is confirmed in the build sheet.
- `e498-equipped.png`: imagegen edit of the owner-supplied boat render, retaining the hull and blue/graphite palette while adding a compact navy Bimini canopy, fore/aft fishing seats, helm and bow displays, stowed bow trolling motor, rods, landing net, tackle storage and boarding ladder. Transparent 1536 × 1024 PNG. Replaces the plain boat render in homepage, product, gallery and social preview. Equipment is illustrative and confirmed through the build sheet.
- `swankey-electric-jet-exploded.jpg`: complete owner-supplied 1672 × 941 exploded system illustration, preserved without cropping or retouching. The technology page explains eight component groups and the electrical/water paths; specific ratings are left to the build sheet. General waterjet principles were checked against HamiltonJet’s HJ Series designer manual, without implying a HamiltonJet component is fitted.

Brand assets are in `public/brand/`; the wave/horizon emblem and upright wordmark form an independent Swankey identity.

The curated edit can be rebuilt with `scripts/prepare-film.swift` and `scripts/encode-film.swift`, passing `12` as the encoder’s third argument to trim export-track padding. `scripts/assemble-film.swift` accepts a JSON frame timeline and produces exact 3-second shots at 24 fps, with an optional audio start offset. It selects the frame at or before each output timestamp, preventing a following shot from leaking into the end of a retained range. The current 12-second film keeps seconds 3–15 of the previous 15-second edit, excluding the prior tail padding frame.
